# Distributed Systems Laboratory

A repository containing practical exercises and experiments focused on distributed systems, concurrency, networking, remote communication, and distributed storage.

## Overview

This project brings together several laboratory assignments designed to explore the fundamental concepts of distributed computing. The repository includes implementations and experiments related to:

- Client-server communication
- Sockets
- Remote Method Invocation (RMI)
- Thread-based concurrency
- Parallelism
- Hadoop HDFS and distributed storage

The main goal is to understand how distributed systems work in practice, including communication, synchronization, resource sharing, fault tolerance, and scalability.
